## 🚀 Phase 1：AI 导航站（第 1-2 周）

**目标**：最快上线，验证流量，建立品牌认知

| 项目 | 说明 |
|------|------|
| **域名** | wuyoai.com |
| **内容** | 收录 200+ AI 工具，按场景分类（写作/绘图/编程/视频/办公等） |
| **技术栈** | VitePress / Astro 静态站，GitHub Pages 或 Vercel 免费托管 |
| **功能** | 分类浏览、搜索、标签筛选、提交收录入口 |
| **变现** | 付费收录（¥200-500/个）+ 联盟推广链接 + 顶部广告位 |

**关键动作**：
- [ ] 站点搭建 + 工具数据填充
- [ ] SEO 基础优化（标题、描述、结构化数据）
- [ ] 提交百度/Google 收录
- [ ] wuyoai.cn 备案（为后续国内镜站做准备）

**这个阶段产出**：一个能用、有流量入口的网站，同时为后续所有内容提供"工具库"基础

---

## 📰 Phase 2：AI 资讯媒体（第 3-8 周）

**目标**：用内容驱动 SEO 流量，建立行业影响力

| 项目 | 说明 |
|------|------|
| **域名** | wuyoai.com/news 子目录（SEO 最友好） |
| **内容** | AI 行业动态、新产品测评、使用教程、深度分析 |
| **更新频率** | 日更 1-2 篇（前期可以用 AI 辅助写，人工审核） |
| **分发渠道** | 官网 + 微信公众号 + 知乎专栏 + 即刻 + 少数派 |
| **变现** | 品牌广告 + 付费专栏（深度分析） + 为 Phase 3 导流 |

**关键动作**：
- [ ] 搭建 CMS（可用 Notion + Super.so，或自建 Headless CMS）
- [ ] 建立内容模板和写作流程
- [ ] 注册各平台账号，同步分发
- [ ] 申请 Google News / 百度新闻源收录

**与 Phase 1 的联动**：资讯中自然嵌入导航站的工具推荐，双向导流

**这个阶段产出**：稳定的内容输出能力 + SEO 流量基础 + 行业认知度

---

## 📚 Phase 3：AI 教程 / 课程（第 2-4 月）

**目标**：知识付费变现，"无忧AI"品牌价值落地

| 项目 | 说明 |
|------|------|
| **域名** | wuyoai.com/learn 子目录 |
| **内容层级** | 免费入门教程 → 付费进阶课程 → 企业定制培训 |
| **课程形式** | 图文教程 + 视频课 + 实操训练营 |
| **定价** | 免费（引流）/ ¥99-299（单课）/ ¥999-2999（训练营） |
| **变现** | 课程销售 + 社群会员（年费制）+ 企业内训 |

**课程选题方向**：
- 🟢 零基础 AI 入门（面向大众）
- 🟡 AI 办公效率提升（面向职场人）
- 🟠 AI 绘图 / 视频创作（面向创作者）
- 🔴 AI 编程 / Agent 开发（面向开发者）

**关键动作**：
- [ ] 设计课程体系（先出 1-2 门 MVP 课程验证）
- [ ] 选择交付平台（小鹅通 / 知识星球 / 自建）
- [ ] 用 Phase 2 的内容做免费引流
- [ ] 建学员社群（微信群 / Discord）

**与前序的联动**：教程中引用导航站的工具 + 资讯中的案例，形成内容闭环

**这个阶段产出**：付费课程产品 + 学员社群 + 稳定现金流

## 🛠️ Phase 4：AI 工具 SaaS（第 4-8 月）

**目标**：自研产品，建立技术护城河

| 项目 | 说明 |
|------|------|
| **域名** | wuyoai.com/tools 或独立子域名 |
| **产品方向**（选 1-2 个聚焦） | ① AI 写作助手 ② AI 客服机器人 ③ AI API 聚合 ④ AI 图片处理 |
| **技术栈** | Next.js / Nuxt + 大模型 API + Stripe/支付宝支付 |
| **定价** | 免费基础版 + Pro ¥29-99/月 + Team ¥199-499/月 |
| **变现** | SaaS 订阅制（MRR 模型） |

**选品建议**（根据技术优势选）：

| 方向 | 开发难度 | 市场竞争 | 推荐度 |
|------|----------|----------|--------|
| AI API 聚合 | ⭐⭐ | 中 | ⭐⭐⭐⭐⭐ |
| AI 写作助手 | ⭐⭐⭐ | 高 | ⭐⭐⭐ |
| AI 客服机器人 | ⭐⭐⭐⭐ | 中 | ⭐⭐⭐⭐ |
| AI 图片处理 | ⭐⭐⭐ | 高 | ⭐⭐⭐ |

**关键动作**：
- [ ] 从 Phase 1-3 的用户反馈中找到真实需求
- [ ] MVP 开发（2-4 周出原型）
- [ ] 内测 → 公测 → 正式上线
- [ ] 用已有流量池做冷启动

**与前序的联动**：导航站推荐自家工具 + 资讯写产品故事 + 教程教怎么用自家产品

**这个阶段产出**：自有 SaaS 产品 + 持续订阅收入 + 技术壁垒

## 👥 Phase 5：AI 社区论坛（第 8 月+）

**目标**：构建用户生态，形成网络效应

| 项目 | 说明 |
|------|------|
| **域名** | wuyoai.com/community 或 bbs.wuyoai.com |
| **功能** | 讨论区 + 工具评测 + Prompt 分享 + 项目展示 + 问答 |
| **技术栈** | Discourse / 自建（基于 Phase 4 的用户体系） |
| **变现** | 社区广告 + 精品内容付费 + 品牌合作活动 + 社区电商 |

**关键动作**：
- [ ] 从已有社群（Phase 3 学员）中孵化种子用户
- [ ] 设计激励机制（积分、等级、创作者分成）
- [ ] 运营活动（AI 创作大赛、工具测评征集）
- [ ] 开放 API 让社区内容反哺导航站和资讯

**为什么放最后**：社区需要足够的用户基数才能自运转，前面四个阶段正好积累用户

**这个阶段产出**：自增长的用户生态 + 最强的品牌护城河

## 🔄 五阶段飞轮效应

```
        ┌──────────────┐
        │   AI 导航站   │ ← 工具库，流量入口
        └──────┬───────┘
               ▼
        ┌──────────────┐
        │  AI 资讯媒体  │ ← 内容驱动，SEO 引流
        └──────┬───────┘
               ▼
        ┌──────────────┐
        │  AI 教程课程  │ ← 知识变现，沉淀用户
        └──────┬───────┘
               ▼
        ┌──────────────┐
        │  AI 工具 SaaS │ ← 产品护城河，订阅收入
        └──────┬───────┘
               ▼
        ┌──────────────┐
        │   AI 社区论坛  │ ← 用户生态，网络效应
        └──────────────┘
               │
               ▼
         反哺所有上游 ←──┘
```

每个阶段的产出都是下一阶段的燃料：
- 导航站的数据 → 资讯的素材库
- 资讯的流量 → 课程的潜在学员
- 课程的学员 → 工具的种子用户
- 工具的用户 → 社区的活跃成员
- 社区的 UGC → 反哺导航站和资讯
